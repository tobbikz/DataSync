# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) spirit:

- Be respectful and constructive in issues, PRs, and discussions.
- No harassment, personal attacks, or exclusionary language.
- Assume good intent; disagree on technical merits.

Report unacceptable behavior privately to the maintainers (see GitHub org profile / [`SECURITY.md`](SECURITY.md) contact path).
